#  Color Catcher Game

Welcome to **Color Catcher**, a fun and simple browser-based game built using **HTML**, **CSS**, and **JavaScript**. Your goal is to catch falling balls with a player bar and score as many points as you can!

---

# How to Play

- Move your mouse left or right to control the player bar.
- Catch the falling colored balls to earn points.
- Every 10 points, the game advances to the next level with a new background and increased speed.
- If a ball reaches the bottom without being caught, the game is over.
- You must restart from **Level 1** if you lose.

---

# Features

-  Scoring system with current and high score
-  3+ Levels with unique backgrounds and increasing difficulty
-  Responsive and smooth player movement
-  Instant restart with a single click
